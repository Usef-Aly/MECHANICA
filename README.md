## Overview

Mechanica is an interactive engineering and physics learning platform designed to transform complex real-world systems into immersive visual experiences.

Instead of relying on memorization, Mechanica allows users to explore engineering concepts through interactive simulations, system blueprints, and dynamic visualizations that reveal how machines, technologies, and natural phenomena actually work.

The project is built around one simple idea:

> **Understanding comes before memorization.**

---

## Why Mechanica?

Traditional education often presents formulas before explaining the systems they describe.

Mechanica reverses this process.

Rather than asking learners to memorize equations, it reconstructs real engineering systems and allows users to experiment with them until the underlying principles become intuitive.

Every lesson answers one question:

> **How does this actually work?**

      ↓

      ↓

## Design Philosophy

Mechanica is inspired by professional engineering software rather than traditional educational websites.

The interface emphasizes clarity, exploration, and experimentation through:

- Minimal visual distractions
- Technical typography
- Engineering dashboards
- Interactive diagrams
- Dark industrial aesthetics
- High information density

The goal is to make learning feel like operating an engineering workstation.

## Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/mechanica.git
```

Move into the project

```bash
cd mechanica
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
